# 🧭 成长仪表盘 (Growth Dashboard)

> 单文件 · 零依赖 · 离线可用 —— Angus 的第一个项目

一个纯前端的个人成长管理面板：从学业、编程、目标习惯到番茄钟、健康、每日复盘，一站式记录并可视化自己的成长。数据全部存在本机浏览器，不联网、不上传。

---

## ✨ 功能一览

| 模块 | 说明 |
|---|---|
| 📊 概览 | 14 项指标聚合 + 近 14 天 Coding 图 + GPA 趋势 + 目标/习惯完成度环 + 近期截止 |
| 📈 本周成长报告 | 近 7 天专注/Coding/习惯率/运动/冥想聚合 + **较上周对比（↑↓）** |
| 📚 课程 / GPA | 百分制成绩自动换算绩点，加权计算 4.0 制 GPA，支持按学期 |
| 💻 Coding 打卡 | 每日时长记录、连续打卡天数、技术栈掌握度 |
| 🚀 项目 / 时间轴 | 项目进度追踪 + 竞赛/实习/考证时间轴与截止提醒 |
| 🎯 目标 / 习惯 | OKR 目标拆解（KR）+ 习惯打卡 + **GitHub 式热力图** + 连续天数 |
| 📅 每日计划 | 按日期的待办清单与完成率 |
| ⏱ 番茄钟 | 25 分钟正向计时、到点响铃不自动停、任务名记录、每日/每任务累计、周趋势 |
| 🗺 大学规划 | 四年 8 学期课表 + 竞赛时间线，按当前日期自动定位学期，课程一键导入 |
| 🏃 健康 | 运动 / 冥想 / 饮水记录 + 7 天趋势 |
| 📝 每日复盘 | 三问 + 五维心境打分（**近 14 天趋势折线**）+ Markdown 自由记录 |
| 🎨 体验 | 暗色模式、实时时钟、跨天自动刷新、移动端适配 |
| 💾 数据安全 | 手动导出/导入 JSON、每日自动快照、File System Access API 自动备份 |

## 🛠 技术栈

- **纯 HTML + CSS + Vanilla JS**，零外部依赖、零 CDN，完全离线可用
- 数据存储：`localStorage`（主数据）
- 自动备份：`File System Access API`（写本地文件）+ `IndexedDB`（存目录句柄）
- 图表全部手写 SVG / CSS（折线、环形、柱状、热力图、树状图），无图表库

## 🚀 快速开始

1. 用 **Chrome 或 Edge** 打开 `dashboard.html`（推荐在桌面放一个快捷方式）
2. 侧边栏点 **「📁 启用自动备份」**，选一个文件夹（如「仪表盘备份」）
3. 以后每次修改数据会自动静默备份，不怕清缓存/换电脑

> 注意：自动备份依赖浏览器能力，Firefox/Safari 不支持时请定期手动「导出 JSON」。

## 💾 数据说明

- 所有数据保存在**当前浏览器的 localStorage**，不联网、不上传服务器
- 清缓存 / 隐私模式会丢数据 → 用「导出 JSON」或自动备份兜底
- 换设备：导出 JSON → 另一台设备「导入 JSON」即可迁移
